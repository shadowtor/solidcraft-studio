Model it once. Print it, render it or texture it.

An Agent Skill that designs parts in SolidCraft through its MCP server, then finishes them: checked in OrcaSlicer for a Bambu H2C, rendered and exploded in Blender, or textured with MaterialCraft and TextureCraft.

InstallView source

Pick the finish

The skill asks which one you want before it models, because it changes the tolerances.

Print

Fits and wall limits scaled to your nozzle (0.2, 0.4, 0.6) and filament (PLA, PETG, ASA, Bambu profiles). Sliced for the H2C on the build plate you name. Supports are designed away first. When they stay, a tight, solid interface lets them peel off clean.

Render

Blender builds the scene, backdrop and lights, and animates exploded views as PNG, MP4 or GIF. Glass and acrylic render in Cycles. EffectCraft adds titles, camera moves and audio.

Textured

PBR maps from MaterialCraft, projected or UV-mapped in TextureCraft, baked, painted and exported as maps or a GLB for vinyl-toy and game assets.

How a session goes

  1. Connect. The skill talks to solidcraft-cli mcp over stdio, limited to your project folder.
  2. Brief. You pick the finish, give sizes and materials. Missing numbers become named parameters with a stated assumption.
  3. Build. Parametric commands, a screenshot after each step, and measurements checked against the brief.
  4. Finish. Print: slicer_check.py slices it for your nozzle, plate and filament. Render: Blender or EffectCraft. Textured: MaterialCraft then TextureCraft.
  5. Hand over. Files, parameters, assumptions and what has not been proven.

Install

You need SolidCraft, Python 3.8+ and an agent that reads skills. OrcaSlicer with Bambu Studio installed (for its profiles), Blender, ffmpeg and the other Craft apps are optional and only enable their finish.

In Claude Code:

/plugin marketplace add shadowtor/solidcraft-studio
/plugin install solidcraft-studio@solidcraft-studio

Or with the installer:

git clone https://github.com/shadowtor/solidcraft-studio.git
cd solidcraft-studio
python tools/install.py --claude --codex     # or --gemini, or --rules for Cursor and Copilot
python skills/solidcraft-studio/scripts/check_setup.py

Start a new session, then ask for something to build.
